Los diez mensajes permitidos quedaron truncados por número y longitud. El URI completo de IAP se vincula con la ruta que el mismo mensaje contiene antes del error y con el ID ya fijado. Las referencias `iam.roles.get` e `iam.serviceAccounts.getIamPolicy` siguen pendientes de su respuesta individual. Para cerrar cada pendiente se admite el éxito nativo de la operación exacta o una lectura equivalente como el principal fijado. La sonda READ protegida por `int` acumula una fila por método y recurso con UTC, identidad, resultado y permiso literal si hubo una denegación. Se conserva la distinción entre 403 explícito, recurso no encontrado, servicio inactivo y falta de credencial vigente. Los `POST :getIamPolicy` consultan políticas. Los permisos observados anteriormente requieren evidencia actual de esa misma identidad para cerrar pendientes de otra operación. El alcance READ no comprende payloads de Secret Manager, entradas Logging, SetIamPolicy, creación, actAs, ni operaciones Terraform sobre el estado.
