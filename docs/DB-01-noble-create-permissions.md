# DB-01 Noble · permisos para la creación y primera observación

Esta matriz cubre los planes revisados de creación y la primera observación de `clipforge-int-db01-noble`. En INT, `clipforgebeta2` es el proyecto ID y `816643438938` es su número. La zona es `us-central1-a`. El controlador usa `clipforge-terraform-int@clipforgebeta2.iam.gserviceaccount.com`. La observación usa `clipforge-deploy-int@clipforgebeta2.iam.gserviceaccount.com`. `admin@ixbalam.studio` verifica y migra el delta IAM, publica la decisión privada y obtiene el serial autenticado. Se conservan las identidades de Debian, PostgreSQL, API, worker y migraciones. [Procedimiento de apply bajo demanda](DB-01-noble-create-observe.md)

La evidencia efectiva procede de los runs y de las llamadas que realizaron. Una asignación observada aporta cobertura derivada. Las restricciones de organización, cuotas, propagación y capacidad pueden impedir una operación en vivo. Las comprobaciones sobre un padre no demuestran creación ni acceso al objeto nuevo.
