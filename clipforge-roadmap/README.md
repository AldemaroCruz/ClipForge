# Planificación de ClipForge AI

Este paquete contiene documentación, **no una nueva versión de la aplicación**. Base: v0.4.1; revisión del roadmap: 1.0; fecha: 30 de octubre de 2026.

Copiar `docs/` a un repositorio privado de trabajo, revisando conflictos con documentación existente antes de reemplazar. No toca `data/`, `cache/`, código o secretos.

- `docs/ROADMAP.md`: dirección, hitos, nube, seguridad, costos, migración y fuentes.
- `docs/BACKLOG.md`: 31 tareas propuestas con prioridad, dependencia y aceptación.
- `docs/PROJECT_STATUS.md`: snapshot real, incertidumbres y próximo incremento.
- `docs/decisions/ADR-001-cloud.md`: decisión de arquitectura propuesta y alternativas.

No hay nube provisionada, pruebas nuevas ejecutadas ni cuentas conectadas. Las cifras son escenarios ilustrativos de cómputo, no una cotización total. La fuente de verdad de seguimiento será la documentación del repositorio una vez incorporada y mantenida.
